赛博背背佳 · Windows 试用版 安装说明
=====================================

谢谢你愿意试用！赛博背背佳是一只住在电脑桌面上的鲸鱼娘桌宠。
它通过摄像头看你的头和肩膀，坐姿一直不好时会提醒你，你坐正了它会给你爱心。
摄像头画面只在你的电脑上处理，不保存、不上传。


一、你的电脑需要
-------------------------------------
· Windows 10 或 Windows 11（64 位）。
· 一个摄像头（笔记本自带的就行）。


二、安装（约 2 分钟）
-------------------------------------
1. 右键这个 zip →「全部解压缩」，解压到一个你找得到的地方，比如「文档」。
   不要在压缩包里直接双击打开，一定要先解压。
2. 打开解压出来的「赛博背背佳-Windows」文件夹，里面有：
     · 赛博背背佳.exe   —— 桌宠本体，双击它
     · 体态测试\         —— 在后台看坐姿的程序，桌宠会自己启动它，不用管
     · _internal\        —— 程序用的文件，不要动
   三样要放在一起，不要单独把 exe 拿出来。
3. 第一次双击时，Windows 可能弹出「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。（这个程序还没有花钱买数字签名，所以 Windows 不认识它。）
   如果杀毒软件拦了，选「允许」或者把这个文件夹加进信任列表。
4. 想以后方便打开：右键「赛博背背佳.exe」→「发送到」→「桌面快捷方式」。


三、第一次打开
-------------------------------------
1. 双击「赛博背背佳.exe」。屏幕右下角会出现鲸鱼娘，任务栏右下角的托盘（小箭头里面）有它的小图标。
2. 跟着首次引导走完，大约 5 分钟：
     欢迎 → 同意书（每一项自己选，不勾“用于研究”也能正常用）
     → 基本资料（都可以选“不想说”）
     → 摆放摄像头 → 校准 → 方向检查
     → 认识桌宠 → 摸底测试（可以“以后再做”）→ 完成
3. 校准时会打开一个“体态测试”的窗口：坐到你平时最舒服、最端正的姿势，看着屏幕，按窗口里的提示做，
   做完窗口会自己关。之后的判断都以这个姿势为准，所以请认真坐好。
   换了座位、换了摄像头位置，可以在菜单「我的数据 → 重新走一遍第一次设置」里重新校准。
4. 如果说摄像头打不开：
   · 打开 设置 → 隐私和安全性 → 相机，把「相机访问」和「让桌面应用访问相机」都打开；
   · 关掉正在用摄像头的软件（视频会议、直播之类），再试一次。


四、平时怎么用
-------------------------------------
· 正常工作就好，它会自己观察。不用一直盯着它。
· 某种坐姿保持太久（比如头前伸、低头、耸肩、歪头），它会先慢慢“学你”变得没精神，
  然后跳起来提醒你是哪个姿势、持续多久了。
· 你坐正后它马上会“嗯！”一下，坐正满约 10 秒，会伸个懒腰送你爱心。
· 不方便的时候，点它的气泡选「稍后」，它会安静 10 分钟。
· 它每小时最多提醒 2 次，不会一直烦你。
· 右键点鲸鱼娘，或者点托盘里的小图标，能找到：暂停、隐藏桌宠、看看奖励、我的数据、退出。
· 鲸鱼娘可以用鼠标拖到屏幕上任何地方；鲸鱼娘旁边透明的地方鼠标能直接点到后面的窗口。


五、把数据发给 gui（只在你同意“用于研究”时）
-------------------------------------
1. 右键鲸鱼娘 → 我的数据 → 导出给 gui…
2. 导出好的 zip 在：你的个人文件夹 → 体态测试数据 → 导出（导出后会自动打开这个文件夹）
3. 请当面拷给 gui（U 盘、数据线都行），或者用 gui 给你的上传链接。
   zip 没有加密，请不要用微信或群聊发。
· 数据里没有你的名字，只有一个随机编号。不想参加了，在「我的数据 → 改勾选」里关掉，
  再把编号告诉 gui，gui 会删掉已经收到的数据。
· 「我的数据 → 删除我的数据」会删掉这台电脑上的全部记录。


六、遇到问题
-------------------------------------
· 鲸鱼娘脚下一直写着“没看到人”或者别的提示：照着那句提示做；还不行就退出桌宠（右键 → 退出）再打开。
· 提醒得太频繁或总是误判：重新校准一次，坐得端正一些，让两个肩膀完整出现在画面里。
· 想把问题告诉 gui：把「个人文件夹 → 体态测试数据 → 运行记录.txt」发给他（里面没有画面，只有文字）。
· 卸载：退出桌宠，删掉「赛博背背佳-Windows」文件夹；想连数据一起删，先在「我的数据」里点「删除我的数据」。
